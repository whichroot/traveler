## Results

The deterministic gate covers 5,604 cases across 18 kernels. Fourteen kernels
exercise the individual operations and precision conversions. Four distinguish
separate multiply/add from FMA and ordered sums from reassociated sums. Every
result is checked as an integer bit pattern against an exact-rational oracle.

Final native output:

```text
IEEE native SM120, PTX SM90: 5604 exact bit-pattern results PASS
IEEE native SM120, PTX SM120: 5604 exact bit-pattern results PASS
IEEE portable: 5604 exact results, SM90/SM120 PTX, policy/refusal checks PASS
```

Both PTX targets passed driver JIT, checked argument packing, resident launches,
downloads, and exact result comparison on SM120. This does not constitute an
SM90 hardware execution test. The numerical operations used `.rn` PTX arithmetic
without `.ftz` or `.approx`.

The same gate passed unoptimized host execution, LLVM O1 execution, and the
compiler's `--emit exe` path. All 18 numerical helper loops were proved
independent. Invalid arity, mismatched carrier types, unsupported package
policies, evaluator execution, and AMDGCN explicit kernels were refused.
Declared-function shadowing passed.

Additional checks:

- Full portable GPU regression suite: PASS, with unavailable native backends
  reported as SKIP by the suite.
- Auto-parallelization soundness suite: 65 PASS, 0 FAIL.
- Refreshed bootstrap: self-hosting fixed point and snapshot freshness PASS;
  no C source compiled in the bootstrap chain.
- Codegen-golden suite: one existing drift, `examples/rns_dyn_matmul.tv`.
  The compiler booted from committed HEAD `40fa34b` reports the same drift.
